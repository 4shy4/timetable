打开日程表
让它变成手机上的 App
  1. 点浏览器右上角菜单 → 选「添加到主屏幕」或「安装应用」
  2. 回到手机桌面，会出现一个「日程表」图标
  3. 以后点图标就能直接打开，没有地址栏，和 App 一样

先装一下证书（iOS 必须，安卓建议）

服务跑在你自己电脑上，用的是自签名证书。不装的话会一直提示"不安全"。

① 下载配置描述文件 （备选）下载 .crt
iPad / iPhone 步骤
  1. 别用无痕浏览（无痕模式下 Safari 不处理描述文件）
  2. 点上面的「① 下载配置描述文件」→ 弹「此网站正尝试下载一个配置描述文件」→ 允许
  3. 打开「设置」→ 顶部会多出「已下载描述文件」→ 点进去 → 安装（要输锁屏密码）
  4. 安装页上那个红色的「未验证」是正常的 —— 这不是 Apple 签发的描述文件就一定这么显示， 它不代表装失败。点右上角「安装」继续就行（这里最容易误以为出错而放弃）
  5. 装好后在「设置 → 通用 → VPN 与设备管理」里能看到 Timetable Local CA， 说明描述文件装进去了
  6. 再进「设置 → 通用 → 关于本机」→ 拉到底「证书信任设置」→ 把 Timetable Local CA 的开关打开（这一步最容易漏；打开之后它才会从「未验证」变成「已验证」）
  7. 回到 Safari 刷新本页 → 再「添加到主屏幕」，这时才是真正的 App
安卓步骤（可选）
  1. 点「下载证书」→ 打开「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」
  2. 选刚下载的文件安装
  3. 回去刷新本页，再「添加到主屏幕」

不想装也行：点「高级」→「继续前往」照样能用， 只是 iOS 上拿不到离线能力和通知。

让「日历」帮你提醒（iPad 关掉 App 也能响）

网页版提醒只在页面开着时有效。订阅到系统「日历」之后，提醒由 iOS 自己发出， 电脑关着也照响。

订阅到系统日历 下载 .ics（一次性导入）
  1. 先试「订阅」：会问「要订阅日历吗」→ 订阅。以后电脑改了日程，iPad 会自动跟着更新
  2. 如果订阅报「验证失败，请编辑URL，然后重试」——那通常是证书还没被真正信任 （日历是后台服务在取，它没法像 Safari 那样点「继续前往」）。 这时改用「下载 .ics」：把文件存到「文件」，点开它 → 日历弹「添加全部」→ 确认。 这条路不需要证书、也不校验 URL，一定能成
  3. 订阅成功后进「设置 → 日历 → 账户 → 已订阅的日历」点这条，确认 「移除提醒」是关闭的（默认就是关的。打开着就不会响提醒）

日历是只读的：在这里勾掉的事会自动从日历里消失，但改日历不会影响本应用。

前提条件

手机和这台电脑要连同一个 WiFi；电脑上的日程表服务要一直在运行（关了就打不开）。

⚠️ 电脑上的服务没有开"局域网模式"，手机连不上。 请关掉日程表，改用 npm run start:lan 启动（或给启动命令加 --lan）。

数据保存在这台电脑上，手机只是用来查看和修改，多台设备看到的是同一份数据。
